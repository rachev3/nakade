# Contributing

1. Branch from `dev`: `feat/…`, `fix/…`, `chore/…`, `data/…`
2. Open a PR into **`dev`** and squash-merge it. `dev` deploys to https://dev.nakade.app
3. Releases: PR **`dev` → `main`**, merged with a merge commit. `main` deploys to https://nakade.app

`main` only accepts PRs from `dev`. Details: [docs/devops.md](docs/devops.md). Architecture: [docs/architecture.md](docs/architecture.md).
